# Dr. Maya Reynolds — Homepage Assignment

Responsive Next.js App Router homepage built with Tailwind CSS configuration and a reusable CSS-variable theme.

## Run locally

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`. The project uses Next.js 14.2.35. Keep the terminal open while the development server runs; press Ctrl+C to stop it.

## Page structure

The page follows the reference homepage's flow: hero, introduction, three audience cards, focus areas, approach, therapist introduction, three service cards, appointment prompt, and footer. It adds the requested Our Office section and FAQs. Layouts adapt from three-column desktop cards to a single-column mobile presentation.

The copy uses the supplied profile details: adult clients; anxiety, panic, trauma, burnout, and perfectionism; CBT, EMDR, mindfulness, and body-oriented techniques; Santa Monica in-person sessions and California telehealth. The theme uses deep blue, mist, warm sand, and coral with Cormorant Garamond and DM Sans. Maya's portrait and office images are referenced from the profile-linked image site; the remaining mood photographs are remote Unsplash images.
